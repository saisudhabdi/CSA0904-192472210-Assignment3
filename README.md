## How to run

Install JDK 11 or later and verify:

```bash
java -version
javac -version
```

Open the required task folder in Command Prompt or Terminal, then run the compile and execution commands in that folder's README. For example:

```bash
cd Task01
javac ATMWithdrawal.java
java ATMWithdrawal
```

Some tasks create their own sample input files when first run. Run each program from its task folder.
